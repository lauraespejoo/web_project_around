# Alrededor de los EE.UU.

Página web interactiva donde el usuario puede compartir fotos de lugares, editar su perfil y reaccionar a las publicaciones.

## Funcionalidad

- Carga del perfil y de las tarjetas desde un servidor.
- Edición del nombre, la descripción y la foto de perfil.
- Creación y eliminación de tarjetas (con ventana de confirmación).
- "Me gusta" en las tarjetas, guardado en el servidor.
- Validación de formularios y mensaje "Guardando..." mientras se envían los datos.
- Ventanas emergentes que se cierran con Esc o haciendo clic fuera.

## Tecnologías y técnicas

- HTML, CSS con metodología BEM y diseño adaptable.
- TypeScript con programación orientada a objetos (clases ES6, herencia, acoplamiento débil).
- Integración con una API REST mediante `fetch`, `async/await` y `Promise.all`.
- Manejo de errores con `try...catch`.
- Git y GitHub Pages.
