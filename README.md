# Tripleten web_project_around_es

## Descripción

Proyecto de práctica desarrollado durante el Sprint 6 del bootcamp de TripleTen. "Around The U.S." es una página interactiva donde el usuario puede editar su perfil, agregar tarjetas de fotos, darles "me gusta", eliminarlas y ver una versión ampliada de cada imagen.

## Funcionalidad

- Editar el nombre y la descripción del perfil desde una ventana emergente.
- Agregar nuevas tarjetas de fotos indicando un título y un enlace de imagen.
- Dar "me gusta" a una tarjeta haciendo clic en el ícono de corazón.
- Eliminar cualquier tarjeta de la lista.
- Ver una versión ampliada de la imagen de cada tarjeta en una ventana emergente.
- Las tarjetas se generan dinámicamente con JavaScript a partir de un array de datos, usando un elemento `<template>` de HTML.

## Tecnologías

- HTML5
- CSS3 (Flexbox, metodología BEM)
- JavaScript (manipulación del DOM, eventos, `<template>`)
- Git y GitHub
